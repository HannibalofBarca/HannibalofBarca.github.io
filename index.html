About Me

I am a robotics engineer specializing in control theory, reinforcement learning, and computer vision. My work focuses on developing robust control architectures and autonomous navigation systems for complex dynamic robots, ranging from quadrotors to quadrupedal dogs and active suspension systems.

Featured Projects

Unitree Go2 RL Policy for Locomotion

A PPO-based RL controller for a Unitree Go2 robot dog in NVIDIA Isaac Sim that has custom rewards and the Raibert heuristic implemented for a stable, natural walking gait, and an actuator friction model implemented for increased simulation accuracy. The model was trained for plane, stepped, and rough terrains.

2D Quadrotor MPC Controller

An SQP and MPC-based trajectory following controller for a 2D quadrotor that has a custom SQP solver implemented for nonlinear trajectory optimization, and a nonlinear MPC framework implemented for stability and disturbance rejection. The controller was designed to execute a full loop maneuver.

Content-Based Image Retrieval for VPR

A Content-Based Image Retrieval system for Visual Place Recognition that has a ResNet-18 model implemented for generating semantic image embeddings, and a KD-Tree spatial indexing structure implemented for efficient nearest-neighbor lookups. The system was evaluated using the NYU-VPR dataset.
